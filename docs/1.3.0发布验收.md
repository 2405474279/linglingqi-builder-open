## 用户可见变化

- 新安装默认 V4。管理员可以独立调整新页面偏好，既有经典、原子和混合页面仍能编辑和渲染。
- 本站区块可复用。原子 FAQ 采用原生折叠，原子选项卡支持成对编辑、键盘切换和独立副本。
- 已有数据、修订和媒体以站点备份保护。对旧版本的支持范围及数据恢复方法见 [升级说明](升级说明.md)。

## 已知边界

- WordPress／PHP 的 Windows 深路径覆盖曾在较早版本验收中漏装长路径文件。建议用站点副本和较短安装根路径验证安装完整性。
- 交互图库、表格及跨站模板包属于后续范围。触控验证使用 Chromium 触屏上下文。

历史条件和候选版记录详见 [V4 候选验收](V4候选验收.md)。
