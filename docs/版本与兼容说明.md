## 1.0.0 首版

以经典页面和文章编辑为首版范围。布局使用容器。内容组件为标题、文本、图片、视频、按钮、图标、分隔线和间距。编辑流程包括响应式预览、草稿、发布及修订。

本地模板库、整站模板导入导出、主题生成器、表单询盘和产品目录均在首版范围之外。页面内容和全局样式继续使用 WordPress 的本地数据。由其他版本创建的页面，应先确认组件都可在首版渲染。

## 旧站迁移与回退

Elementor 及凌凌漆各版共享内部类和数据键。更换版本前备份数据库及上传目录，在副本上逐页核对已有组件、全局样式和前台渲染。同一站点只启用一个版本。

迁移时重点检查原页面是否依赖其他版本的表单、产品组件或主题模板。替换这些内容后再发布。如果需要回退，使用原站版本重新验证页面。涉及数据恢复时，以更换前的站点备份为准。

## 推送与发布

1. 每次推送前更新 [README](../README.md) 并完成 [推送前文档检查](开发文档.md#推送前同步文档)。发布新版本时，同步 `linglingqi-builder.php` 的插件头部和 `ELEMENTOR_VERSION`、`readme.txt` 的 Stable tag 与发布记录。上游兼容基线只在实际更新上游基线时调整。
2. 每个稳定版、补丁版和候选版都要同步新增一条 [升级说明](升级说明.md)，记录升级来源、行为变化、数据与兼容影响、验证步骤和回退方式。
3. 保留 GPLv3 文本、上游版权和第三方库随附的许可说明。在公开文档和示例中使用通用内容。
4. 打包时以 `linglingqi-builder-open/` 为 ZIP 的顶层目录。核对 ZIP 内容、SHA-256 和安装入口，再用最终包走一遍本地发布验收。 [许可文本](../linglingqi-builder-open/license.txt) · [开发验收](开发文档.md)
