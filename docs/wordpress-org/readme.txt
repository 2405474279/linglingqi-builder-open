== Description ==

LingLingQi Builder (凌凌漆可视化编辑器) is an open-source visual page builder based on Elementor 4.3.6. The editor opens from the WordPress page screen and stores content, styles and reusable sections in your WordPress installation.

* Build layouts with containers, headings, paragraphs, images and buttons.
* Reuse sections within the same site.
* Share styles across elements with classes and variables.
* Add accordions and tabs and preview responsive layouts.

[Getting started (Simplified Chinese)](https://bpvips.com/3262)
and [illustrated component tutorials](https://bpvips.com/collection/linglingqi-builder).

== Installation ==

1. Install and activate LingLingQi Builder from the WordPress Plugins screen. Use one active builder from the Elementor family on a given site.
2. Open the Pages screen and choose the LingLingQi editing action for a page.
3. Add elements, preview the result and save or publish the page.

== External services ==

The local editor and section library require no external account. Optional Google Maps, externally hosted video and SoundCloud widgets use the corresponding provider when an author adds and configures them. Imported templates or user-entered external media URLs can contact the selected host.
