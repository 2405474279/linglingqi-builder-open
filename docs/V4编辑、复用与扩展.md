# 凌凌漆 V4 编辑、复用与扩展

适用于凌凌漆开源编辑器 1.2.0 至 1.3.0。上游兼容基线为 Elementor 4.3.6。插件运行于站点自己的 WordPress，使用普通主题时可以打开编辑器、保存、发布和复用区块。

## 编辑页面

1. 从 WordPress 后台打开「网站可视化构建器」并创建测试页。V4 优先时，组件面板先显示「原子化元素」。可先插入 Flex，再添加原子标题、段落、图像、按钮或分隔线。经典优先时，可从「布局」「基本」「常规」插入经典组件。
2. 用 Flex 的 `gap`、元素外边距或容器内边距设置留白。根容器可在桌面设为横向，在手机断点改为纵向。已有经典页面可继续使用「布局」「基本」「常规」中的经典组件。
3. 用样式类统一多个元素的样式。定义品牌颜色变量，并让按钮的共享类引用它。创建尺寸变量并把它用于字号、间距或内边距。尺寸变量接受带单位的数值，例如 `16px`、`1.25rem`，同一个变量可以被多个兼容属性引用。
4. 调整单个元素时，切到该元素的局部样式。先确认视口，再保存。发布后在退出登录的浏览器打开页面，核对内容、断点和媒体。

## 使用本站区块

- 编辑器顶栏的「我的区块」提供图文双栏、三列图文卡片、图片墙、双按钮 CTA。预设示例图随插件安装，插入和显示都可使用本地请求。
- 选中原子 Flex、DIV 区块或 Grid 根容器，可以保存当前容器为本站区块。换到另一页后从库中插入。每次插入生成新的元素 ID 和局部样式 ID；同站共享类、变量和本地媒体继续引用同一来源。
- 重命名和删除只操作区块原稿。已经插入的内容和媒体可以继续使用。若编辑用户可以看见区块但不能重命名或删除，核对该用户对原稿的 WordPress 权限。

## 原子 FAQ

1. 在 1.3.0-rc.1 的组件面板搜索「原子 FAQ」「FAQ」或「常见问题」，插入组件，初始包含两个示例问答。
2. 在画布中点击折叠标题展开条目，选中标题或答案中的原生段落编辑。也可选中 FAQ 根节点，展开内容面板中的问答条目，使用「编辑问题」或「编辑答案」定位。条目「名称」用于编辑器导航，公开文本由原生问题和答案元素提供。
3. 用条目列表的添加、删除和排序把手调整顺序，保留至少一项。在设置中选择初始首项展开或全部收起，以及同时允许一个或多个条目展开。各 FAQ 的单项展开按自身分组。
4. 在样式面板使用共享类和颜色／尺寸变量。切换到手机断点，可以只覆盖某个元素的本地样式。使用 Tab、Enter 或 Space 检查发布后的前台折叠，也可在手机上触屏检查。组件使用浏览器原生 `details` 和 `summary`。
5. 要跨页复用，选中 FAQ 根节点，在「我的区块」点击「保存所选折叠区块」。每次插入都会得到独立元素和局部样式 ID。同站共享类、变量及媒体仍引用原定义，删除原稿后已插入页面继续使用自己的副本。
6. `FAQ Schema` 新建时关闭。启用后，根据有问题、有答案的原生条目输出 FAQPage 结构化数据。发布后检查输出与实际内容。

FAQ 继续使用 `e-accordion` 根和原生 `e-accordion-item-*` 子树。沿用 `default_state`、`max_expanded`、`show_icon` 和 `faq_schema`。已有原子 Accordion 页面可继续编辑，经典手风琴仍使用既有经典组件。

## 原子选项卡

1. 在 1.3.0-rc.2 的组件面板搜索「选项卡」，选择「原子选项卡」。新插入的组件包含两对标签与内容面板。
2. 切换画布上的标签，然后编辑当前面板中的原子元素。也可选中根节点，在内容面板的条目里按「编辑标签文本」或「编辑内容面板」进入对应元素。公开标签文本在原生段落中编辑，「导航名称」用于编辑器。
3. 从条目列表增删和重排，至少保留一对。标签和面板一起移动。删除当前项时选择原位置的下一项，如果删除的是最后一项，就选择前一项。可以将其他条目设为默认项。
4. 发布后可用点击或触屏切换。用 Tab 进入选中的标签，左右方向键自动移焦并展示对应面板，支持循环。Home 和 End 可跳到首尾。焦点只进入当前显示的面板及其可操作内容。
5. 选中根节点，打开「我的区块」并点击「保存所选选项卡」。跨页插入的副本保留站点共享类和变量。各副本具有独立的元素、局部样式、标签和面板 ID。

原子选项卡沿用 `e-tabs`、`e-tabs-menu`、`e-tab`、`e-tabs-content-area` 和 `e-tab-content`。经典、嵌套和已有原子选项卡仍可使用原数据。

## 管理员切换新建页偏好

从「网站可视化构建器 → 编辑器模式」选择 V4 或经典，再确认保存。偏好调整组件分类、搜索排序及空白画布的默认布局。两组组件仍可手动选择，既有页面的元素类型和样式照常保留。V4、经典和混合页面在两种偏好下都能查看、编辑和保存。

首次显式设置前，按旧选项解读站点的偏好。未知或冲突的值使用经典优先。设置表单只保存独立的偏好选项 `linglingqi_new_page_mode`，原子运行时始终可用。旧启用或关闭入口只提示改到后台确认。[历史选项与升级说明](升级说明.md)

## 扩展、能力发现与内容识别

扩展在独立 WordPress 插件中实现，使用凌凌漆开源版已有的加载和注册钩子。推荐从以下源文件中的第一批原子能力开始。

| 用途 | 接入点 |
| --- | --- |
| 检查运行时 V4 | 在凌凌漆初始化后读取 `Plugin::$instance->experiments->is_feature_active( 'e_atomic_elements' )`，并确认目标元素已注册。新建页偏好由 `Opt_In::prefers_v4()` 读取，编辑器可从 `elementorCommon.config.linglingqiPreferV4` 取得。 |
| 注册原子 widget | 在 `elementor/widgets/register` 中注册自己的 `Atomic_Widget_Base` 子类。参考 [原子标题](../linglingqi-builder-open/modules/atomic-widgets/elements/atomic-heading/atomic-heading.php)。 |
| 注册原子容器 | 在 `elementor/elements/elements_registered` 中注册自己的 `Atomic_Element_Base` 子类。参考 [Flex](../linglingqi-builder-open/modules/atomic-widgets/elements/flexbox/flexbox.php)。 |
| 发现实际能力 | 读取站点的 `elements_manager->get_element_types()`、`widgets_manager->get_widget_types()` 和编辑器 `elementor.config.atomic`。注册能力、面板可见性、实际验证结果应分别核对。 |
| 确认内容类型 | 遍历文档的 `elements`。布局类型看 `elType`，`elType: widget` 的类型看 `widgetType`。用已注册实例和原子基类确认，兼容逻辑避免用用户可见名称或单靠 `e-` 前缀猜测。 |
| 原生样式数据 | 原子元素的 `settings` 保存带 `$$type` 的值。元素的 `styles` 定义局部样式及设备变体。`settings.classes` 引用站点共享类及元素局部样式。共享类与变量按当前站点的活动 Kit 解析。 |

后台和编辑器的 WordPress 权限仍然有效。对现有内容保留组件类型、属性键和 prop 类型。新增控制项时应定义 prop schema、控件配置和渲染模板，并验证编辑画布、前台、移动断点、保存和复开。

通用基础原子元素及四套组合沿用。交互图库、表格和跨站模板包列入后续版本。已有兼容类型仍可能出现在配置中，验收支持范围见 [候选验收](V4候选验收.md)。工业产品、询盘、授权和计费属于可选扩展。

上游标签、许可证、资源差异和保留基线的理由见 [来源记录](upstream-provenance.md)。
