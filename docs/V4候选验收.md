### 基线问题和实现边界

在 rc.1 隔离站复现了原子选项卡面板不可见，以及匿名切换后面板显示样式与 `hidden` 属性不一致。新入口沿用 `e-tabs`、原生标签栏和面板的类型及已有属性键，按顺序配对。前台用渲染实例 ID 连接 `aria-controls` 和 `aria-labelledby`，同时更新选中属性、键盘焦点和 `hidden`。

左、右方向键按实际阅读方向循环移动焦点，并自动激活对应面板。Home、End 到达首尾。编辑器删除当前项后，激活原位置的下一项，末项选择前一项。标签与面板使用同一组原生操作及撤销记录。 [使用与复用](V4编辑、复用与扩展.md#原子选项卡) · [W3C Tabs 模式](https://www.w3.org/WAI/ARIA/apg/patterns/tabs/)

首轮预检在编辑器成对增删及重排之后复现了 Alpine 对已脱离 DOM 节点访问 `parentElement.children` 的异常，并影响后续面板激活。后续包让标签索引计算容忍已脱离节点，忽略无效索引，画布事件写入实际渲染实例的状态键。

### 加载等待及边界

- PHP 7.4 组合的三个编辑页面实测约 47.5、52.4、39.7 秒进入可编辑状态，均加载了 `editor.min.js` 并自行关闭遮罩。
- 较新组合并行验收时，有一次普通编辑者的冷加载耗时约 223.6 秒。iframe 的 DOM 在发起导航后约 113.8 秒完成，其载入事件在约 131.9 秒结束，后续文档全局类请求约 222.7 秒返回，遮罩随后关闭。慢段落在 iframe 载入后的挂载与 AJAX／REST，相关请求未出现 5xx。普通编辑者访问仅限管理者的类用量接口得到预期的 403。
- 同一最终包、同一个混合页、同一角色使用新浏览器上下文串行复开，约 17.6 秒取得原生视图，最后一批文档类请求约 23.8 秒完成，约 24.8 秒关闭遮罩。确认实际加载 `common.min.js`、`editor.min.js`、`editor-canvas.min.js` 和 `editor-elements.min.js`。后台偏好套件的八次打开耗时 26.3–30.6 秒。串行复验未复现长时间遮罩，现有数据表明并行负载与等待相关，尚不足以归因到单一接口或确认版本间的性能差异。
- 预检及最终 PHP 日志中的 WordPress.org 连接警告来自隔离站的外部联网限制。某些较新后台导航偶见 Chromium 的 ViewTransition 取消信息。记录这些环境现象与混合页保存时实际修复的插件警告分开。
- WordPress 6.8 普通编辑者会话中，核心 `wp-auth-check.min.js?ver=6.8:2:655` 两次报告读取未定义对象的 `hasClass`。实测仍可复开并保存，匿名回读通过。该通知的触发条件尚未专项定位。
- 此次根层粘贴修复作用于新的粘贴操作。模式切换和升级不批量改写已有文档。
