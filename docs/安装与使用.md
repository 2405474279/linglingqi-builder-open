# 凌凌漆开源版安装与使用

适用于 1.1.0。可以用它制作和编辑 WordPress 页面或文章，在容器中排列内容，并按桌面、平板和手机分别调整版式。

## 安装和打开编辑器

1. 确认环境满足包头声明的 WordPress 6.8 和 PHP 7.4 下限。首版验收使用 WordPress 7.1.4、PHP 8.3.30 和 Twenty Twenty-Five。
2. 从 WordPress 后台进入「插件 → 安装插件 → 上传插件」，选择 ZIP，然后安装并启用。同一个 WordPress 站点仅启用一个 Elementor 或凌凌漆版本。现有站点先在副本上验证。 [1.1.0 安装包](https://github.com/2405474279/linglingqi-builder-open/releases/download/v1.1.0/linglingqi-builder-open-v1.1.0.zip)
3. 打开「页面 → 新建页面」，或在页面列表找到已有页面，点击「使用凌凌漆编辑」。也可以从「网站可视化构建器」进入新建或编辑入口。文章编辑入口取决于插件设置中启用的内容类型。
4. 中文界面可在「设置 → 常规 → 站点语言」选择简体中文。浏览器中的界面文字可能随账号语言变化，按对应的控件功能找到入口。

## 从空白页面到可预览草稿

1. 在画布点击加号，选一个容器布局。简单页面可以从单列开始。
2. 从左侧组件面板添加标题、文本、图片或按钮。点选画布上的组件，使用面板的「内容」「样式」「高级」修改文字、外观和间距。
3. 给内容图片填写有意义的替代文字。给按钮设置实际目标，预览时点开核对链接。
4. 用顶部设备选项查看桌面、平板、手机布局。重点检查标题换行、图片裁剪和容器间距。
5. 从「保存选项」选择「保存草稿」。使用「预览更改」看实际渲染，确认无误后点击「发布」。已发布页面的直接更新会改变访客看到的内容。

## 组件面板

| 分类 | 组件 |
| --- | --- |
| 基础 | 标题、图片、文本编辑器、视频、按钮、分隔线、间距、Google 地图、图标 |
| 常规 | 图片盒、图标盒、图片轮播、基础图库、图标列表、计数器、进度条、推荐语、选项卡、手风琴、社交图标、提示、SoundCloud、短代码、HTML、菜单锚点、侧栏、阅读更多、评级、路径文字 |

容器用于布局。开启容器时，面板默认提供可嵌套内容的选项卡和手风琴。经典选项卡、手风琴、切换和星级评分继续支持已有页面。HTML 的可见性取决于当前账号权限。地图、SoundCloud 和采用外部来源的视频会由所选服务加载。

## 常见问题

| 现象 | 检查方法 |
| --- | --- |
| 页面列表没有编辑入口 | 核对插件已启用、设置中对应的内容类型已启用，以及当前账号有权编辑该页面。 |
| 画布一直加载 | 检查预览是否能打开、插件脚本是否正常加载，以及浏览器控制台和 WordPress 日志中的首个新错误。 |
| 保存后前台看起来没变 | 先核对保存结果和页面状态。草稿改动通过预览核对。已发布页面可重新打开前台地址并检查站点缓存。 |
| 迁入的页面缺少组件 | 盘点页面原有组件，逐个替换为当前版本提供的组件，再检查页面和设备版式。 [版本与兼容说明](版本与兼容说明.md) |
