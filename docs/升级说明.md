# 凌凌漆开源编辑器升级说明

从 WordPress 后台打开「插件 → 安装插件 → 上传插件」，选择目标版本的 ZIP。在已有安装上确认「使用上传的插件替换当前插件」。同一站点只启用一个 Elementor 或凌凌漆编辑器版本。

## 升级前与升级后

1. 核对当前插件版本、目标版本和安装包 SHA-256。备份 WordPress 数据库、上传目录和当前插件包。在站点副本上先做一次升级。
2. 在副本上传目标包并确认插件保持启用。打开一张既有页面，检查编辑器加载、组件、响应式样式、媒体和全局样式。另建一张测试页，保存并发布，用新会话复开，再以访客身份检查前台。
3. 如需回退，先备份现状，再装回经过验证的旧包，检查旧包是否支持升级期间写入的内容。若需恢复升级前的数据库与媒体，先保留升级后要留下的业务内容和附件。恢复旧快照会覆盖快照之后的写入。

## 1.2.0-rc.2 V4 安全切换候选版

- **适用路径**　可全新安装，或在副本上用后台上传替换 1.1.0、1.2.0-rc.1。各版本及运行环境的实测结果见候选验收。
- **行为变化**　从「网站可视化构建器 → 编辑器模式」选择新建页优先使用 V4 或经典。组件面板和空白画布布局按偏好提供默认入口。经典、V4 和混合页的既有组件、保存及前台渲染继续可用。
- **历史数据**　新选项尚未保存时，读取 `elementor_experiment-e_opt_in_v4` 和 `elementor_experiment-e_atomic_elements`。缺省、空值、`default` 或 `active` 随默认选择 V4；任一 `inactive`、冲突或未知持久值沿用经典优先。独立的容器实验原先关闭时，未确认偏好的站点也沿用经典优先。
- **保存偏好**　有管理员权限的用户确认表单时只写入 `linglingqi_new_page_mode`。升级和普通加载保留两个历史选项、页面树、修订、共享类、变量和区块。旧 V4 AJAX 和 REST 入口提示改用后台设置页。rc.1 因关闭原子运行时而暂时隐藏的内容，在 rc.2 可重新渲染。
- **升级后检查**　保存并复开经典、V4 和混合页面。在同一站点切换两次新建页偏好，确认两种默认入口及匿名内容。若依赖旧操作接口，改用管理员设置页确认。
- **修复**　原子内容在页面根层粘贴时分配独立元素 ID。普通编辑者保存混合页时，经典标题清理只遍历元素树，并保留页面设置。
- **回退**　想恢复经典的默认入口时，可直接切换偏好。确需降级时，先在副本验证旧包能处理当前内容。rc.1 仍可依历史选项关闭原子运行时，1.1.0 的原子支持范围更小。保留候选包、数据库和媒体备份，以便恢复原子内容。

## 1.2.0-rc.1 V4 候选版

- **适用路径**　已实测从 1.1.0 覆盖升级，也可在独立测试站全新安装。从 1.0.0 开始时，先升级到 1.1.0 并验收经典页面，再测试本候选版。
- **行为变化**　新装和未明确选择的 1.1.0 站点默认启用 V4。显式关闭、相互冲突或无法识别的历史状态保守维持关闭。现有经典内容保留原有数据结构。候选版增加原生布局、颜色与尺寸变量、共享样式、四套预设和站内区块复用。
- **升级后检查**　先保存一张经典页，再新建原子页。核对面板顺序、桌面和手机布局以及匿名渲染。若旧站曾主动关闭 V4，先确认升级后仍是经典模式。
- **模式回退**　从「网站可视化构建器 → 编辑器模式」查看提示并确认切换。关闭期间，原子内容可能暂时无法渲染或编辑。先重新启用 V4，再编辑含原子元素的页面。切换保留原子文档和区块数据。
- **版本回退**　降回 1.1.0 前，在站点副本确认已有页面不依赖 V4。需保留升级期间新增的 V4 内容时，保留可运行该内容的候选版副本与备份，再处理旧版站点。

## 1.1.0 基础与常规组件

- **适用路径**　从 1.0.0 覆盖升级，或全新安装。
- **行为变化**　恢复「基础」和「常规」组件，加入嵌套选项卡和手风琴模块，并使用更新后的凌凌漆标志。经典选项卡、手风琴、切换、星级评分继续支持已有文档。
- **升级后检查**　打开并保存已有页面，核对经典组件和匿名渲染。新建一张测试页，确认图库、轮播等所需组件可插入。使用嵌套组件时同时检查容器布局和移动端。
- **版本回退**　降回 1.0.0 前，盘点升级后使用的新增组件。需要旧站继续显示的内容，先在副本用 1.0.0 支持的组件替换或验证。

## 1.0.0 首版

- **适用路径**　开源版首版，适用于独立 WordPress 安装。从其他 Elementor 或凌凌漆版本换入时，按站点迁移处理并先在副本验证。
- **功能范围**　容器布局和八种基础内容组件，支持响应式预览、草稿、发布和修订。
- **首次安装检查**　验证页面编辑入口、一个基础组件保存重开，以及匿名前台。迁入既有文档时，逐页检查使用的组件和全局样式，尤其是表单、模板或产品组件。
- **迁移回退**　安装前记录原站的插件版本、活动主题和数据备份。必要时在副本重新启用原插件版本，并用原站数据核对页面、样式和媒体。

## 后续每个版本的维护约定

每个稳定版、补丁版和候选版都在本页顶部增加独立条目，在提交版本更新时同步完成。条目写明适用的来源版本、行为变化、升级步骤、数据与兼容影响、升级后检查及回退方式。区分已实测的路径与建议先在副本验证的路径，并链接到该版本的安装包、校验值和验收记录。沿用的通用步骤可引用本页，版本特有的注意事项写在该版本条目中。
