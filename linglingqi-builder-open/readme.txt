面向 WordPress 的开源基础可视化编辑器，基于 Elementor 4.3.6。

== Description ==

使用容器、标题、文本、图片、按钮等常用组件编辑文章和页面。支持拖拽、响应式设置、修订、草稿、预览与发布。站点样式和页面内容保存在自己的 WordPress 站点中。

== Installation ==

1. 在独立测试站上传并启用安装包。同一 WordPress 站点只运行一个 Elementor 或凌凌漆编辑器版本。
2. 打开「页面」，选择「使用凌凌漆编辑」。
3. 添加组件并预览，保存草稿或发布。
