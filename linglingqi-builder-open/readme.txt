面向 WordPress 的开源基础可视化编辑器，基于 Elementor 4.3.6。

== Description ==

默认使用 V4 原子元素创建页面。可以使用 Flex 布局、图文、按钮、分隔线、响应式样式、共享类、颜色与尺寸变量，以及本站区块库。经典页面可继续编辑。站点样式和页面内容保存在自己的 WordPress 站点中。

== Installation ==

1. 在独立测试站上传并启用安装包。同一 WordPress 站点只运行一个 Elementor 或凌凌漆编辑器版本。
2. 打开「页面」，选择「使用凌凌漆编辑」。
3. 添加组件并预览，保存草稿或发布。
