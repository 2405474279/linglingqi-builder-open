# 凌凌漆可视化编辑器（开源版）

面向 WordPress 页面和文章的开源可视化编辑器，兼容基线为 Elementor 4.3.6。页面、样式和区块保存在自己的 WordPress 站点中，无需 SaaS 账户。

从 WordPress 后台上传插件 ZIP 并启用，再从「页面」打开「使用凌凌漆编辑」。同一站点只启用一个 Elementor 或凌凌漆版本。已有站点先备份数据库和媒体，并在副本上按目标版本的步骤升级。[安装与使用](docs/安装与使用.md) · [升级与回退](docs/升级说明.md)

1.3.1 首次接入 WordPress 后台在线更新。运行 1.3.0 或更早版本的站点须先上传 1.3.1 安装包覆盖一次。安装并启用后，后续 GitHub 正式版可从「仪表盘 → 更新」检查并安装。[在线更新条件](docs/安装与使用.md#后台在线更新)

## 1.3.0 功能

- 使用原生 Flex、Grid、标题、段落、图片、链接按钮和分隔线编辑响应式页面。已有经典页面可继续编辑。
- 使用共享样式类、颜色和尺寸变量统一设计，也可为单个元素设置局部覆盖。
- 从「我的区块」插入图文双栏、三列图文卡片、图片墙和双按钮 CTA，或保存容器并跨页插入独立副本。
- 从 V4 面板插入原子 FAQ，并在内容面板新增、删除和重排问答。 [原子 FAQ 使用](docs/V4编辑、复用与扩展.md#原子-faq)
- 原子选项卡支持成对增删和重排、键盘导航和站内复用。 [原子选项卡使用](docs/V4编辑、复用与扩展.md#原子选项卡)

新装默认优先使用 V4。管理员可从「网站可视化构建器 → 编辑器模式」切换新建页偏好。V4 和混合页面在经典优先下仍可显示、编辑和保存。[V4 使用与扩展](docs/V4编辑、复用与扩展.md) · [原生示范页与依赖](examples/v4-design/README.md)
