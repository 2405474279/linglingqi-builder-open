# 凌凌漆 V4 原子设计示范

样本来自隔离 WordPress 中的实际编辑器发布。原生文档及依赖使用 1.2.0-rc.1，兼容基线 Elementor 4.3.6。测试页站点地址已替换，归档没有用户、账户、Cookie 或数据库转储。

- [原生文档](document.json) 包含组件树、原生 prop 值、局部样式与响应式变体。
- [依赖清单](dependencies.json) 包含两个共享类、品牌色、标题字号、卡片间距、断点和三张随包提供的本地示例图。

## 在另一个测试站复现

1. 安装候选包并确认 V4 已启用。保留目标站桌面默认布局、平板上限 1024 px 和手机上限 767 px，或把样本变体映射到目标站的断点。
2. 把依赖清单中的三张图映射到插件安装后的媒体 URL，也可以复制到本站媒体库并改用新地址。将文档里的 `example.invalid` 示例媒体 URL 换成映射后的地址，将 `site_links` 中的首页占位符换成目标站首页。
3. 在目标站活动 Kit 创建清单中的站点变量，记录新旧变量 ID 映射。然后创建两个站点样式类，套用清单中的原生样式变体，其中的变量引用使用新 ID。
4. 创建用于测试的页面。保留原生元素类型和 `$$type` 数据，按上一步映射替换 `settings.classes` 内的共享类 ID，以及局部样式里的变量 ID。通过本版本的编辑器命令插入根元素，再用正常的编辑器保存动作发布。在已有页面插入时，为副本生成新的元素 ID 与局部样式 ID。可参考插件里的本地区块模块，查阅服务端局部样式重映射和客户端插入命令。
5. 验证三个卡片在桌面为三列，在手机上为单列。两个 CTA 共享品牌色。第二张卡片保留独立的内边距覆盖。

WordPress 集成可使用已有的站点变量和全局类 REST 路由。具体参数以本版 [变量 REST 注册](../../linglingqi-builder-open/modules/variables/classes/rest-api.php) 和 [全局类 REST 注册](../../linglingqi-builder-open/modules/global-classes/global-classes-rest-api.php) 为准。登录权限和请求 nonce 由 WordPress 管理。样本是原生文档与依赖数据，目标站的 ID 与媒体 URL 需按站点解析。
